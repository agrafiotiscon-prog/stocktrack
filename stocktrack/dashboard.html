    How the numbers were made

    Built to avoid fooling ourselves

    • Entry is the open of the first session after the filing, the first price anyone could act on.
    • Every feature uses only filings and outcomes that were public before entry.
    • The test design was written down before the first run. Later changes are bug fixes, each logged.
    • Significance comes from monthly portfolio returns, with corrections for testing many ideas.
    • 2006–2015 found the leads; 2016 onward checks them. Leads found by looking are judged only on the live test.

    Is it still working on new buys?

    Every qualifying new buy is logged each weekday morning, before its first trading session, then tracked for a year. Only those rows count as a forward test, because nobody can tune them after the fact; they carry an F in the table. The ledger began on Oct 19, 2026 with a backfill of earlier buys, which are tracked but don't count.

    Method · how much to trust this

    How the numbers were made

    Built to avoid fooling ourselves

    • Entry is the open of the first session after the filing, the first price anyone could act on.
    • Every feature uses only filings and outcomes that were public before entry.
    • The test design was written down before the first run. Later changes are bug fixes, each logged.
    • Significance comes from monthly portfolio returns, with corrections for testing many ideas.
    • The pre-registered tests used 2006–2015 first and 2016 onward as a re-test. The leads on this page (CFO and other executive buys, run-up buys) were found by looking at all 21 years, so only the live test can confirm them.
    • "Comparable stocks" means an equal-weighted average of every still-listed US stock over $1 trading $100K+ a day, leaving out each stock's own post-buy months. It isn't matched on size or sector.

    What it can't tell you

      Research, not investment advice.
